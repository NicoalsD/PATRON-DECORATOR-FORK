    ¿Por qué no crear una subclase para cada combinación?

    Con cinco servicios opcionales existen 32 subconjuntos posibles, incluso antes de considerar el orden. Los decoradores reutilizan cinco clases y una base. La herencia se usa para compartir el contrato; la combinación se resuelve por composición.

    Un caso real:
    logística farmacéutica modular.

    Una operación puede requerir aislamiento térmico, registro de temperatura, documentación de cada entrega, seguro y prioridad. Esos servicios cambian según la carga. Modelarlos como envolturas permite combinarlos sin alterar el transporte base.

    El alcance de este taller

    El caso está inspirado en necesidades de transporte reales. Los valores y plazos son sintéticos. La aplicación implementa la cotización y la composición; el empaque, los sensores y la entrega se representan como capacidades del modelo.
